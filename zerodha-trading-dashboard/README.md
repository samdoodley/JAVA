# Zerodha Trading Dashboard

A professional real-time trading dashboard for Zerodha trading bots.

## Technology Stack

- Python
- Flask
- Flask-SocketIO
- SQLite
- SQLAlchemy
- HTML5
- CSS3
- JavaScript
- Chart.js

## Features

- Live Dashboard
- Real-Time P&L
- Open Positions
- Closed Trades
- Trade Analytics
- Equity Curve
- REST APIs
- Socket.IO

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```
